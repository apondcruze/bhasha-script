# Bhasha-Script
A custom LALR compiler and IDE built with Python and PLY. This project allows users to write code using Bengali keywords and native digits.

## ✨ Features
- **Bangla Keywords**: Supports `dhoro` (variable), `dekhao` (print), `jodi` (if), `tahole` (then), and `nahole` (else).
- **Unicode Support**: Native support for Bengali digits `০-৯`.
- **Custom Error Handling**: Friendly error messages like "Syntax bhul hoyeche!".
- **Integrated Editor**: Built-in GUI for writing and running code.
